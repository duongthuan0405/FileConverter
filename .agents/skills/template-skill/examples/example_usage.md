# Ví dụ thực tế (Example Usages)

Tài liệu này chứa các ví dụ cụ thể về dữ liệu đầu vào (Input), quy trình xử lý, và kết quả mong muốn (Output) để Agent hiểu chính xác cách thực hiện.

## Kịch bản 1: Thao tác thông thường
- **Mục tiêu:** Mô tả ngắn gọn mục tiêu cần đạt được.
- **Đầu vào (Input):** Ví dụ tham số, đường dẫn tệp tin, dữ liệu mẫu.
- **Thực thi:** Lệnh hoặc hành động Agent cần chạy.
- **Kết quả mong muốn (Output):** Định dạng kết quả mẫu hoặc thông báo thành công.
